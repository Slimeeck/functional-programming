# ЛР6. Замикання та декоратори як HOF — варіант 4

**Тема варіанта:** Авторизація користувачів.

**Обов'язкові компоненти:** closure для списку ролей; параметризований `@require_role`; `@timed`.

**Завдання:** дозволяти виклик функції лише користувачам потрібної ролі.

**Спеціальні вимоги:** `@wraps`; власний виняток; логер як залежність.

## Обов'язкові вимоги

- Щонайменше два замикання, одне з яких утримує змінний стан через `nonlocal`.
- Щонайменше три параметризовані декоратори або два декоратори та одна їх композиція.
- У кожному декораторі — `functools.wraps`; типізація — `ParamSpec` і `TypeVar`.
- Залежності `clock`, `sleep`, `logger`, `time_fn` передаються через `Callable`.
- Без реальних `sleep` / мережевих затримок у тестах.
- Перевірити збереження `__name__`, `__doc__`, `__wrapped__`.
- Тести на нормальне виконання, винятки, граничні параметри та стан closure.
- Структура: `closures.py`, `decorators.py`, `app.py`/`main.py`, `tests/`, `README.md`, `requirements.txt`/`pyproject.toml`.
- Перевірка: `pytest`, `mypy`, `black`, `ruff`.
